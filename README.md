# Alex Morgan Portfolio

GitHub Pages-ready portfolio for AI video direction and automation workflow services.

## Publish

1. Upload all files in this folder to your repository root.
2. Keep `index.html` in the root.
3. Add videos to `assets/videos/` and workflows to `assets/workflows/`.
4. Update the sample paths in `ai-videos.html` and `automation-workflows.html` to match your actual filenames.
5. Enable GitHub Pages from the repository Settings > Pages.

The presentation slide HTML files are included separately for reference or presentation tooling.
